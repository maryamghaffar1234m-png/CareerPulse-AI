## 🌟 What is this?
CareerPulse AI is a smart tool that reads your CV and tells you which jobs are best for you!
It checks your skills, your education, and your experience, and shows you:
- ✅ Your top career matches (like Software Engineer, AI Engineer, Teacher).
- 🎯 Your match percentage (how ready are you for this job).
- 📚 What skills you need to learn next to get that job (The Gap).

## ✨ Amazing Features
- 🧠 Reads PDF, Word, and Image files (with OCR).
- 🛠️ Automatically finds your skills (Python, Java, etc.).
- 🏆 Matches you with 200+ different job profiles (Tech, Medical, Business, etc.).
- 📊 Shows a beautiful progress bar for your match score.
- 🎨 Modern, attractive, and easy-to-use design.

## 💻 How to Run on Your Computer
(For developers only)
1. Open your terminal.
2. Type: `cd backend`
3. Type: `pip install -r requirements.txt`
4. Type: `python -m uvicorn main:app --reload`
5. Open your browser and go to: `http://127.0.0.1:8000`

## 🛠️ Tech Used
- Python (Backend)
- FastAPI (Web Framework)
- Pytesseract (Image Reading)
- HTML, CSS, JavaScript (Frontend)
